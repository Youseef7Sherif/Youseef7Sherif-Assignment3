# CSharpBasicsAssignment

## Description

This project is a small C# console application that demonstrates the basic concepts covered in Lecture 01.

The assignment is organized into several focused parts, with each part demonstrating a specific C# concept through code and output.

## Topics Covered

* Variables and data types
* Implicit and explicit casting
* Value types and reference types
* Structs and classes
* Stack and heap memory concepts
* Scope
* Compound assignment operators
* Bitwise operators
* Boxing and unboxing
* Parsing
* XOR and LeetCode 136 — Single Number

## Project Structure

```text
CSharpBasicsAssignment/
├── CSharpBasicsAssignment.csproj
├── Program.cs
├── Order.cs
├── Point.cs
├── STACK_HEAP.md
├── README.md
└── ANSWERS.md
```

### Files

* **Program.cs** — Contains the main program flow and the methods used to demonstrate the assignment parts.
* **Order.cs** — Contains the `Order` class used to demonstrate reference type behavior.
* **Point.cs** — Contains the `Point` struct used to demonstrate value type copy semantics.
* **STACK_HEAP.md** — Contains the stack and heap diagrams for Part E.
* **ANSWERS.md** — Contains the short answers for Part G.
* **CSharpBasicsAssignment.csproj** — Contains the project configuration and .NET settings.

## How to Run

Make sure .NET 10 SDK is installed, then run the following commands from the project directory:

```bash
dotnet build
dotnet run
```

The program will execute the assignment parts and print labeled output to the console.
